# D5 trick format (`d5-trick`, version 1)

A trick (a "skill") is one JSON file, `skills/<name>.json` here and `~/vector/tricks/<name>.json` on the robot's Pi.
It describes face-screen animation,
sounds, speech and small moves. It's data only: nothing in it runs as code. `tricks.py`
validates everything and pre-renders frames and sounds before D5 moves. Steps run strictly
one after another, so a sound never plays while frames are being sent (doing both at once
jammed D5's SDK service on 2026-10-07).

On the Pi, check a file without the robot: `~/vector/bin/python ~/vector/tricks.py <name>`.
Example: `skills/pacman.json` (generated by `sources/make_pacman.py`).

## Top level

```json
{
  "format": "d5-trick",
  "version": 1,
  "name": "pacman",                 // required; a-z 0-9 - _ (max 40); also the file name
  "title": "Pac-Man",               // optional, max 60 chars
  "description": "…",               // optional, max 300
  "author": "…",                    // optional, max 60
  "palette": {"eye": "#f0cd1e"},    // optional colour names for shapes and "eyes" (max 32)
  "sounds": {"intro": {…}},         // optional named sounds (max 32)
  "frames": {"eyes": [ … ]},        // optional named frames, used as {"ref": "eyes"} (max 64)
  "steps": [ … ]                    // required; run in order
}
```
`download_trick` adds `"source": "<url>"`.

## Frames

The face screen is 184 x 96 pixels, black background. A frame is one of:

- a list of shapes, drawn in order (max 200)
- `{"ref": "<name>"}`: a frame from `"frames"`
- `{"image_base64": "<PNG/JPEG, exactly 184x96>"}`

Shapes (coordinates in pixels, may go off-screen; `fill` is `#rrggbb`, a palette name or a
colour name, default white):

| shape | fields |
|---|---|
| `{"rect": [x0, y0, x1, y1]}` | `radius` (rounded corners) |
| `{"circle": [cx, cy, r]}` | |
| `{"ellipse": [x0, y0, x1, y1]}` | |
| `{"pie": [cx, cy, r]}` | `start`, `end` (degrees, 0 = right, clockwise): e.g. Pac-Man is start 40, end 320 |
| `{"polygon": [[x, y], …]}` | 3-64 points |
| `{"line": [x0, y0, x1, y1]}` | `width` 1-40 |
| `{"text": "…"}` | `at` [x, y] (default centre), `size` 6-90, `anchor` (default `mm` = centred) |

## Sounds

Each named sound is one of:

- `{"library": "chime"}`: `~/vector/sounds/chime.wav`; add `"else": {…}` as a fallback when that file isn't there
- `{"wav_base64": "…"}`: an embedded WAV, 16 kHz 16-bit mono, max 1 MB
- `{"melody": {"unit_seconds": 0.2, "root_hz": 523.25, "tail_seconds": 0.15, "voices": [...]}}`:
  1-4 voices played together; each voice is `{"wave": "square"|"triangle"|"sine", "duty": 0.25,
  "level": 0.55, "attack": 0.004, "release": 0.03, "notes": [[semitones from root, length in units], …]}`;
  use `null` instead of semitones for a rest
- `{"sweeps": [...]}`: pitch sweeps played one after another; each is `{"wave", "duty", "from_hz",
  "to_hz", "seconds", "level", "attack", "release", "curve_power"}` (1 = straight line; 2 = falls fast, then slows)

Sounds are normalised to 90% volume and max 20 s each. Very short sounds (under 0.35 s) are padded
with silence before playing, because D5 fails to play them otherwise.

## Steps

| step | what it does | limits |
|---|---|---|
| `{"show": frame, "hold": 0.5}` | one frame; it stays up `hold` seconds unless replaced | hold 0.05-30 |
| `{"frames": [frame, …], "fps": 17, "hold_last": 0.5}` | an animation; the last frame stays `hold_last` s | ~17 fps max |
| `{"sound": "name", "volume": 80}` | play a named sound (the last frame stays up meanwhile) | volume 0-100 |
| `{"say": "text"}` | speak | 200 chars |
| `{"wait": 1.0}` | pause | 0-10 s |
| `{"head": 20}` / `{"lift": 0.5}` | head angle (-22 to 45°) / lift height (0-1); add `"wait": false` to start the move and go straight on to the next step | |
| `{"turn": 90}` | turn in place, + = left | ±360° |
| `{"drive": 100, "speed": 80}` | drive straight, + = forward | ±200 mm, 10-150 mm/s |
| `{"animation": "GreetAfterLongTime"}` | one of his own animations (trigger or anim name) | |
| `{"eyes": "#00ff80"}` | eye colour (he may change it back later) | |
| `{"repeat": 3, "steps": [ … ]}` | repeat a block | 1-50 times, nested at most 2 deep |
| `{"choose": [{"label": "escape", "weight": 2, "steps": [ … ]}, …]}` | pick one branch at random, by weight, each time the trick runs | 2-8 branches, nested at most 2 deep |

`choose` makes a trick vary: `perform_trick(name, variant="<label>")` forces a branch, and `list_tricks`
shows a trick's labels as its endings. When checking a file, every branch is checked, and the
trick's length is counted using its longest branch.

Whole trick: at most 400 steps (repeats count), 900 frames and about 90 seconds; files at most 2 MB.
A trick with `turn`, `drive` or `animation` steps drives D5 off his charger first.
Tip: to show a picture while a sound plays, put the `show` (with a long enough `hold`) just before the `sound`.
To move while a picture or speech changes, give the move `"wait": false` and put the `show` or `say` right
after it: e.g. `{"lift": 1.0, "wait": false}, {"show": {"ref": "closed"}, "hold": 4}` raises the lift as the
eyes close (see `peekaboo.json`). Older engines ignore `"wait"` and just do the move first.
